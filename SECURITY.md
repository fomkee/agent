# Security Policy

## Supported versions

Security fixes are provided for the latest published release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository:
open the **Security** tab and select **Report a vulnerability**. If that option
is unavailable, contact the Fomkee maintainers privately before disclosing the
issue publicly.

Do not include API tokens, Heartbeat URLs or secrets, customer endpoints,
request bodies, production configuration, or private repository content in a
public issue. We will acknowledge a complete report as soon as practical,
coordinate remediation and disclosure with the reporter, and publish a
security release when users need an update.
